# Security and privacy

This app stores health content in the user's browser and does not send it to an application backend. It is not app-encrypted storage. A compromised device, malicious browser extension, or compromised app update can expose records. Backups and reports contain private information in readable form. See the README for storage and hosting limits.

## Reporting a vulnerability

Use this repository's **Security → Report a vulnerability** option for a private report. Do not post exploits with real records, credentials, or personal information in public issues. Use synthetic records and describe the affected version, steps, and impact. This is a personal open-source project with no guaranteed response time.

## Supported version

Security fixes target the latest main branch. Before updating your own deployment, export a backup, review the changes, and test with artificial data. Never paste a health backup into Git, a support ticket, or a public chat.
